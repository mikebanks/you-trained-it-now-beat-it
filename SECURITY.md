# Security policy

This is a self-contained classroom teaching demo, not a production security filter. Do not submit real credentials, personal information, or suspicious messages from real accounts.

For a vulnerability that could expose information or execute untrusted content, use this repository's **Security → Report a vulnerability** option. Do not post exploit details or private data in public issues. If that option is unavailable, contact Michael Banks at https://www.michaelbanks.org/contact and describe how to arrange private disclosure.

Only the latest published version is maintained. No response-time or support guarantee is offered. For ordinary teaching or browser bugs, use the issue templates.
